# 动态绝对稀疏架构：任务自适应曲线的重大发现 (Task-Dependent Sparsity Curves)

## 核心发现
在进行 2D Block 动态稀疏架构的基准测试（Benchmark）时，我们观察到了一个极具启发性且反直觉的现象：**并不存在一个“全局完美”的稀疏曲线，最优的稀疏策略高度依赖于下游任务的类型。**

### 1. 分类与阅读理解任务 (如 HellaSwag)
* **表现最佳曲线**：**倒 U 型曲线（Inverted U-Shape）**
* **策略特征**：保留底层和顶层的权重（10% 抛弃率），重度压缩中层权重（最高抛弃 70%）。
* **理论支撑**：选择题和分类任务本质上是对粗粒度概念的映射，不需要维持长程的复杂逻辑推理。只要底层的语法/基础表征提取正常，并且顶层的词表映射投影（Vocab Projection）不出错，中层的逻辑深度可以被极大地牺牲。
* **数据验证**：倒 U 型曲线在 HellaSwag 上的准确率达到了 **47%**，远超线性抛弃曲线的 34%。

### 2. 长文生成与自回归任务 (如 MT-Bench / Writing)
* **表现最佳曲线**：**线性递增曲线（Linear Dropout）或正 U 型曲线**
* **策略特征**：保留底层和中层的权重，逐渐/重度压缩高层权重。
* **理论支撑**：自回归生成极其容易受到“累积误差”和“蝴蝶效应”的影响。模型必须依赖中间层（Middle Layers）来维持世界知识的提取和长程上下文的连贯性。如果对中层施加极端的 70% 稀疏率，模型会瞬间丧失逻辑记忆，导致陷入无意义的循环（例如不断重复 "the the the"）。相反，只要中层逻辑保留完整，即使顶层权重被部分丢弃，模型依然能输出连贯的文章。
* **数据验证**：当应用倒 U 型曲线（丢弃中层）时，生成任务完全崩溃（裁判判决 0:5 惨败）。而在早期的线性递增抛弃测试中，生成任务仍然能够输出具备完整逻辑的长文本。

## 未来指导意义
在工业级落地时，稀疏框架必须具备**“任务感知（Task-Aware）”**的能力：
- 当用户提交 Prompt 并明确为“知识问答/总结/分类”时，激活 **Inverted U-Shape** 以换取最大提速并保持核心判别智商。
- 当用户进行“长篇创作/逻辑推演/代码编写”时，激活 **Linear or U-Shape**，誓死保卫中层参数，宁可降低少许提速比例，也要避免生成崩溃。
